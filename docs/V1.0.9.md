# HACS 1.0.9

- Neue Einrichtungen am gemeinsamen Kontodienst benötigen keine Einladung mehr. Sensoren und Zustimmung bleiben erforderlich; Alexa wird danach einmal verknüpft.
- Kontoanlage ist je Internetanschluss und Gesamtkapazität begrenzt. Wiederholungen nach Verbindungsfehlern verwenden denselben lokal gespeicherten Einrichtungsschlüssel.
- Bestehende Einträge übernehmen die neue Dienstadresse erst nach erfolgreicher Prüfung. Zugangsdaten, Sensoren und Alexa-Verknüpfung bleiben erhalten. Eigene Server bleiben unverändert; ältere Server können weiterhin Einladungen verlangen.
- Klarere Pflicht-/Optional-Hinweise bei PV und BKW.

Nach dem HACS-Update Home Assistant neu starten. Eine erneute Kontoanlage oder Alexa-Verknüpfung ist für vorhandene Nutzer nicht erforderlich. Das funktionierende Echo-Widget wird durch dieses Update nicht ersetzt.

Prüfung: 28 Python- und 24 Backendtests; zwei getrennte neue Haushalte am echten Dienst einschließlich OAuth-Abruf und anschließender Löschung. Echte HA-Oberflächenabnahme und externe Bestandsupdates bleiben in der offenen Abnahme.

Rückkehr: Vorherige Version 1.0.8 bleibt verfügbar. Bereits eingerichtete Konten funktionieren damit weiterhin. Neue automatische Einrichtungen benötigen mindestens 1.0.9; der alte Einladungsweg bleibt am Server erhalten.
